# Legacy MACE raw umbrella data

This folder supplies the raw retained CV values used for the GPR diagnostics.

- `mh1` is MACE-MH1.
- `off23` contains the MACE-OFF23 runs.

The old files were written every 0.5 fs.  The evaluation driver applies the
Figure-3 1+9 ps selection: discard 2,000 frames and use the following 18,000.
